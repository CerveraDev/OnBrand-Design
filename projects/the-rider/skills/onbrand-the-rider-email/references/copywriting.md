# Copywriting

## Default Voice

Write polished, confident, warm Rider Residences copy. Avoid hype, generic luxury cliches, and overexplaining. The copy should feel premium, architectural, and useful.

## Concept Development Output

When the user asks for help shaping the campaign, provide:

- Campaign angle options
- Headline options
- Optional subheading options
- Subject line options
- Preview text options
- CTA options
- Recommended visual direction

## Email Copy Components

Include these when building a full campaign:

- Subject line
- Preview text
- Hero headline
- Optional hero subheading
- Body copy
- CTA label
- Optional secondary copy modules

## CTA Guidance

Prefer clear action labels. Examples:

- Schedule a Private Tour
- Request a Private Appointment
- View Availability
- Learn More
- RSVP

Match CTA to campaign goal. Do not invent contact details or URLs; use supplied values or leave placeholders.
